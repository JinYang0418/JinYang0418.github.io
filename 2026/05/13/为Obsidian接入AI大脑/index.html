为Obsidian接入AI大脑

发表于 2026-05-13 更新于 2026-05-14 分类于 技术分享

这里以最通用、最省钱的 Copilot 插件 + DeepSeek 模型​ 组合为例，教你如何完成配置。

01 必备“通行证”—— 获取 API Key

Obsidian的AI插件本质上是一个“空壳”，它们需要连接到外部的大语言模型（LLM）才能工作。因此，你需要先去大模型服务商那里申请一个 API Key

  • 访问 DeepSeek 开放平台注册账号；
  • 进入“API Keys”页面，点击“创建 API Key”；
  • 复制这串以 sk- 开头的密钥妥善保存。

02 安装插件

在 Obsidian 设置 ￫ 社区插件 ￫ 浏览中，搜索 Copilot 并安装启用。

03 设置 API 钥匙

  • 进入 Obsidian 设置 ￫ Copilot Settings ￫ Basic Settings ￫ API Keys ￫ Set Keys。
  • 将你刚才复制的 DeepSeek API Key 填入对应的框中。

04 开始使用

保存设置后，点击左侧菜单栏的机器人图标，右侧就会弹出Chat面板。在下拉菜单中选择你的 DeepSeek 模型，就可以开始愉快地调教你的笔记了！

最后的一点叮嘱：无论是 DeepSeek 还是 OpenAI，使用 API 都会产生微小的费用，记得在平台充值一点余额。此外，千万不要把极其私密敏感的密码或个人绝密信息放在笔记里让 AI 处理，以防泄密。
