知止而后有定

发表于 2026-05-11 分类于 生活日记

今夜静坐复盘，想通了困扰自己二十余年的一桩心事。

从少时到如今，我始终陷在一层自我怀疑里：世人眼里该正经学、必须学的课业与技能，我总难沉心坚持，常常半途而废；反倒对那些被世俗归为「旁门左道」「不务正业」的事，比如街舞、网站搭建、传统数术，却能自发沉进去，熬通宵也不觉得累，满心都是欢喜与热忱。我曾一度以为，是自己心性不定、没有长性，难成正经事。

近日读到《大学》，一句“知止而后有定”，忽然点破了这层迷障。原来我从来不是没有长性，只是搞反了学习的根本顺序。

世人多是随大流而动：看社会需要什么、旁人都在学什么，便逼着自己往里头钻，却从来没问过自己：我要去哪里？我要做成什么事？而真正能让我沉下心的学习，从来都不是先盲目攒知识，而是先立住目标，再以目标为锚，缺什么补什么，什么有用学什么。

就像此前我想搭建一个完全属于自己的 Blog 网站，从一片空白到落地成型，我没有盲从网上铺天盖地的「程序员成长路线」，逼着自己按部就班死磕枯燥的代码体系，而是始终锚定“做成专属博客”这个核心目标，目标指向哪里，我的脚步就跟到哪里。

我先选购配置服务器，用 WordPress 框架搭起网站雏形；因不满足于模板的同质化效果，想要实现专属个性化定制，便针对性学习了 Python 后端语言和基础前端知识。最终不仅做成了完全专属的独立博客，更在这个过程里，把原本枯燥的编程知识，扎扎实实化成了自己的真本事。

原来我此前的半途而废，从来不是能力不够，而是那些被推着学的东西，没有锚定我的本心，没有落脚到我真正想做的事上。心无定止，自然难有恒力。

真正的学习，从来不是逼着自己迎合世俗的标尺，在别人划定的赛道里硬熬；而是先立住自己的目标，守住自己的「止」，而后心有定见，事上用功，需要什么便学什么，热爱什么便深耕什么。那些曾被我归为「不务正业」的热忱，从来不是我的缺点，恰恰是我本心最真实的指引。

知止有定，因用而学，方是长久之道。
